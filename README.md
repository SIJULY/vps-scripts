# VPS Scripts - X-UI 自动化多 IP 路由补丁

这个仓库主要存放 VPS 管理与优化的相关脚本。目前包含专门针对原版 `vaxilu/x-ui` 的**多 IP 出站自动化路由补丁**。

## 🌟 核心功能

当你在一台 VPS 上配置了多个公网 IP（例如甲骨文附加 IP）时，默认情况下所有出站流量都会走主 IP。
本补丁能够让 X-UI 支持**“多独立公网出口”**：在面板中添加节点时，只需要填写对应的“监听 IP”，程序会自动拦截配置，并在底层补全对应的 `sendThrough` 出站路由规则。

**特性：**
- 🛡️ **无缝拦截**：无需魔改 X-UI 面板源码，对原版直接生效。
- 🤖 **全自动化**：安装后，只要在面板内修改/新建节点，路由全自动绑定，无需在 SSH 中执行任何重启。
- 批量部署极其友好，不会影响未绑定 IP 的节点。

## 🚀 一键部署指令

在已经安装好原版 [vaxilu/x-ui](https://github.com/vaxilu/x-ui) 并且至少登录过一次面板的机器上，执行以下命令：

```bash
bash <(curl -sL https://raw.githubusercontent.com/SIJULY/vps-scripts/main/xui-patch.sh)
```

## 📖 日常使用说明

1. 部署补丁成功后，打开你的 X-UI 网页控制面板。
2. 进入“入站列表”，点击添加节点。
3. 在 **监听 IP (Listen IP)** 这一栏中，填入你的辅助私有 IP（例如 `10.0.1.93`）。
4. 正常配置其他项（端口、协议等），点击“保存”/“添加”。
5. 🎉 **大功告成！** 该节点的出站流量已被自动绑定到了该 IP 对应的公网出口上。
